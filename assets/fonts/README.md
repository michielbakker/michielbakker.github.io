Variable font (wght 200-800), split into the two subsets this site actually
needs: `latin` covers the body text and the en/em dashes and double dagger;
`latin-ext` exists for the handful of author names with diacritics outside
Latin-1 (e.g. the "ů" in the publication list). The browser downloads only
the subsets a page uses, via the unicode-range on each @font-face.

Refresh from https://fonts.googleapis.com/css2?family=Manrope:wght@200..800
(request with a modern browser User-Agent to get woff2 URLs).
